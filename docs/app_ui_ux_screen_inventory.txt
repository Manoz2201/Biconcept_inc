BICONCEPT APP — UI/UX INVENTORY
================================
App: BiConcept (Flutter, Windows + Android)
Theme: dark Material 3 (coral primary #E8877A, navy cards)
Layout: compact < 800px (phone/narrow), desktop sidebar, wide >= 1100px (agent rail)
Formula: Amount = Quantity × Unit Rate. GST 18% (default) / HVAC 28% (default).
Status values: Drafted · Completed · Finalized
CRM stages: Lead · Contacted · Site visit · Quotation · Negotiation · Won · Lost
Estimate types (presets): Interior Estimate · Design · Construction TurnKey Estimate · plus Custom
Catalog units: sqft · pcs · lumpsum · seat · rft · mtr · step

This file lists every screen, then every visible element, button, field, and what it does.


================================================================================
0. APP START / SHELL (EstimateHomePage)
================================================================================
Entry: lib/main.dart → MaterialApp home = EstimateHomePage
Startup (not UI): Appwrite live sync install; ScheduleService.start() for calendar/notifications.

LOADING SCREEN
  - Full-screen CircularProgressIndicator (primary coral)
  - Shown until the rate-card catalog JSON loads

ERROR SCREEN
  - Centered text: "Could not load catalog: {error}"

SHARED CHROME (after catalog loads)
  Left sidebar (width >= 800 only)
    - Brand text: "biconcept"
    - Nav item Dashboard  (index 0) — opens Dashboard tab, clears search
    - Nav item Estimates  (index 1) — opens Estimates tab, clears search
    - Nav item Clients    (index 2) — opens Clients tab, clears search
    - Nav item Calendar   (index 3) — opens Calendar tab, clears search
    - Nav item Rate card  (index 4) — opens Rate card tab, clears search
    - Nav item Settings   (index 5, pinned at bottom)
    - Logo image assets/data/logo.png
    - Caption "BiConcept"
    Selected item: coral filled 48×48 icon tile

  Bottom NavigationBar (width < 800 only)
    Same six destinations: Dashboard, Estimates, Clients, Calendar, Rate card, Settings
    Selecting a tab clears the search query

  App header (all tabs)
    - Title (lowercase): dashboard / estimates / clients / calendar / rate card / settings
    - Search field (Estimates, Clients, Rate card only)
        Estimates hint: "Search client or project"
        Clients hint:   "Search client, phone or project"
        Rate card hint: "Search work type, scope or area"
    - Agent IconButton (smart_toy)
        Wide screens: expand/collapse the right DeepSeek agent rail
        Narrow screens: open Agent dialog (380×560)
        Tooltip: "Collapse agent" / "Expand agent"
    - CircleAvatar with person icon (display only, not tappable)

  Right agent rail (width >= 1100 only)
    See SCREEN 12 — DeepSeek agent

  FloatingActionButton (depends on tab)
    Dashboard: +  → starts New estimate flow
    Estimates: + / "New estimate"  → starts New estimate flow
    Clients:   person_add / "New client"  → New client dialog
    Other tabs: no FAB

  Background: Appwrite auto-sync. On resume, syncs then reloads drafts, clients, catalog.

1. DASHBOARD
================================================================================
File: lib/ui/dashboard_page.dart
Scrollable page of analytics from saved estimates.

STAT CARDS (tap to jump to Estimates)
  1. Estimates
     - Count of all saved estimates
     - Delta: "% vs last month"
     - Tap → Estimates tab, no status filter

     - Delta: "% vs last month"
     - Tap → Estimates tab, no status filter

     - Compact INR of finalized estimates
     - Tap → Estimates tab filtered to Finalized
  4. Completed
     - Count of completed estimates
     - Tap → Estimates tab filtered to Completed
  Each card also shows a north-east arrow (visual only).

CHART: Value by work type
  - Bar chart of line amounts grouped by work type
  - Empty: "No line items yet"
  - Hover/tap tooltip: work type name + compact INR

CHART: Estimate value over time
  - Line chart of last 12 months
  - Hover tooltip: compact INR
  - X-axis: every other month label

CHART: Status mix
  - Donut of Drafted / Completed / Finalized counts
  - Legend with counts
  - Empty: "No estimates yet"

FAB (shell): + → New estimate flow

  Chips lists: Cached areas, Cached work types ("{sno}. {name} ({scopeCount})"), Cached scopes ("{workType}: {name}")

  Help: CSV backup of LocalCache; cloud sync is background; Sync is manual
  Buttons:
    - Backup  → confirm "Backup LocalCache" (Cancel / Save CSV)
                file picker save; then "Backup saved" dialog with path
                Backup saved actions: Copy location · Open (reveal in Explorer) · OK
    - Restore Backup → pick CSV; confirm "Restore LocalCache" (Cancel / Restore)
                       replaces company defaults, recent jobs, custom catalog
                       then silent Appwrite sync
    - Sync    → AppwriteAutoSync.syncNow; disabled while busy (spinner)
                Snackbar: counts of clients/estimates/catalog items, or "Cloud sync is not available…"
  Caption: "Waiting for automatic sync" or "Last synced DD/MM/YYYY HH:MM"

SECTION: Company defaults
  Fields:
    - Brand on quotations
    - Company address (shown under logo on quotation headings)
    - Contact no. (hint +91 8178869148)
    - GST % (digits)
    - HVAC GST % (digits)
  Button: Save company defaults → LocalCache prefs (empty brand/address/phone fall back to defaults 18/28 GST)
  Snackbar: "Company defaults saved on this PC"

SECTION: DeepSeek agent
  Help: API key lets the agent search rate card, list/edit quotations, add scopes, save
  Button: Use DeepSeek defaults → fills base URL + model
  Fields:
    - Base URL (hint https://api.deepseek.com/v1)
    - Model (hint deepseek-chat)
    - DeepSeek API key (obscured; eye icon toggles visibility)
  Button: Save API settings → SettingsStore on this machine
  Snackbar: "DeepSeek API settings saved on this machine"

9. NEW ESTIMATE FLOW
================================================================================
File: lib/ui/new_estimate_flow.dart
Pushed from Dashboard FAB, Estimates FAB, Clients "New estimate".
Optional prefill: initialClient, initialProject.
Restores last project, carpet area, recent areas/work types from local cache.

APP BAR: "New estimate" + system Back
HORIZONTAL STEPPER (tappable only for completed/current steps)
  1 Project · 2 Areas · 3 Types · 4 Scopes · 5 Terms
FOOTER
  Back (hidden on step 0) · Next  /  on last step: "Build quotation"

STEP 0 — Project
  Fields:
    - Client (required to continue)
    - Project / location
    - Carpet area (sqft, optional) — helper: scales sqft quantities from similar jobs
  Estimate type ChoiceChips: Interior Estimate, Design, Construction TurnKey Estimate, Custom
    Custom opens Estimate type picker
  Date ListTile → date picker 2020–2035
  Next blocked snackbar: "Enter a client name"

STEP 1 — Areas
  Help: "Select area types from past jobs, or type a new name."
  Field: Area type name + Add (+) / Enter
    Empty + Add → Add area type dialog
    Existing name → select that area
    New name → CatalogRepository.addArea then select
  Suggestions: FilterChips of catalog areas (toggle select)
  Caption: "{n} selected"

STEP 2 — Types
  Help: "Select work types for this estimate, or add a new one."
  CheckboxListTile per work type: "{S.No}. {name}" / "{n} scopes · added"
  ListTile "Add work type" → Add work type dialog; auto-selects new type
  Next blocked snackbar: "Select or add at least one work type"

STEP 3 — Scopes
  Entering this step with none selected auto-selects typical + recent scopes
  Help: "Select scopes, enter quantity to calculate amount, or add a new scope."
  ExpansionTiles: "{Work type}" or "{Work type} · {area}" if type uses areas
    Empty: "No scopes yet. Add one below."
    Checkbox per scope: name / unit · rate · "typical" · "added"
    If selected: Quantity field + read-only Amount (qty × suggested rate)
    ListTile "Add scope" → Add work scope dialog; auto-selects with default qty
  Next blocked snackbar: "Select or add at least one work scope"

STEP 4 — Terms
  Heading: "Terms and conditions"
  Embedded TermsAndConditionsForm (see SCREEN 11)
  "Build quotation" builds EstimateDraft, remembers selection in cache, replaces this route with Quotation editor

15. NON-SCREEN BEHAVIOUR THAT AFFECTS UX
================================================================================
- Catalog load failure blocks the whole app (error screen).
- Appwrite auto-sync refreshes estimates, clients, and catalog when data arrives or app resumes.
- Follow-up save and payment schedule create local notifications (Android + Windows; Asia/Kolkata).
- Recording a received installment cancels that installment's 9am collect notification.
- Dual-app Android: launch config "biconcept (Android phone)" uses --device-user=0.
- Windows launch: "biconcept (Windows)" — no Android-only flags.
